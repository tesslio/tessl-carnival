# Workshop: build your own software factory with context

This is where the 90-minute session starts. Pick a path below and follow its
guide: it has everything you need, from setup to the tracks. Stuck? Raise your
hand: a facilitator will come over.

A **software factory** is a set of automations on a repository. When something
happens, such as a label on an issue, a review on a pull request or a time on
the clock, an agent does one job in a cloud environment and opens or updates a
pull request. Code review checks it, and sends it back to the agent until it's
ready to merge.

## Pick your path

There's no right or wrong path. Either way you end up with the same factory on
your own fork of the carnival, and the same finish line: **your change, live at
your own GitHub Pages link**. The only difference is how you set it up, so pick
the one you prefer.

| Path                                      | Pick it if                                                         | You need                                                                   |
| ----------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **[With your agent](workshop/agent.md)**  | You use a coding agent and want to see the setup, choice by choice | A coding agent, git, Node 22.13 or later, the GitHub CLI and the Tessl CLI |
| **[In the browser](workshop/browser.md)** | You'd rather click through it, or your laptop can't install tools  | A GitHub account and a browser                                             |

**Using a coding agent?** Open it in your clone of the carnival and paste
**Read workshop/agent.md and take me through the core path, one step at a
time**.

## The session

The room comes together three times: the kick-off, a checkpoint and show and
tell. The rest you do at your own pace, with your path's guide.

| Time | Block                  | What happens                                                                      |
| ---- | ---------------------- | --------------------------------------------------------------------------------- |
| 0:00 | Kick-off (10 min)      | What we're building and the two paths. Then go.                                   |
| 0:10 | Core path (40 min)     | Carnival running, factory set up, first issue shipped, change live on Pages.      |
| 0:50 | Checkpoint (10 min)    | Progress, live links on screen, what people learned, help for anyone still going. |
| 1:00 | Tracks (20 min)        | Pick one optional track.                                                          |
| 1:20 | Show and tell (10 min) | Share carnivals, talk about what the factory caught.                              |

The core path is the only part everyone needs to finish. Everything after it is
optional, so you can keep going if you're quick, and still leave with a working
factory if you're not.

## For the agent

If you're a coding agent and the person asks about the workshop, follow
[`workshop/agent.md`](workshop/agent.md). If they want to set up in the browser
instead, point them to [`workshop/browser.md`](workshop/browser.md): that path
is theirs to click through, so don't run its steps for them.
